# Contexto conservado

Objetivo: simulador personal de mid lane para Windows, local, con duelos 1 vs. 1 y una IA que mejore sus decisiones en lugar de recibir estadísticas artificiales. El usuario aclaró que quiere los nombres reales de LoL para práctica personal: Irelia contra Sett, Vladimir y Mel. Esto reemplaza el criterio inicial de nombres originales. Los modelos siguen siendo provisionales.

Prioridad: controles precisos, hitboxes, tiempos, combate común para jugador y IA, y progresión hacia rivales que posicionen, esquiven, predigan, farmeen y castiguen errores. IA tradicional primero; aprendizaje automático como investigación posterior.

Tecnología: Unity 6 LTS, C#, URP. Modelos y animaciones provisionales al comienzo. Minimizar configuración manual del usuario; Codex implementa y prepara, el usuario instala Unity y prueba.

Etapas: prototipo funcional → habilidades y pasivas → rivales tácticos, oleadas, torres y economía → arte/animación y calibración → Windows.

Requisito agregado por el usuario durante la implementación: opción de poner pausa al juego. Incluida con Esc y botones del menú, con congelación del tiempo de simulación y reinicio disponible durante pausa.

Editor instalado posteriormente: Unity 6000.6.5f1. Proyecto adaptado a esa versión, con URP 17.6.0 y Test Framework 1.8.0 incluidos en el editor. El script de ejecución busca la instalación de Unity Hub automáticamente. Copia previa a la migración: TestResults/BeforeUnity6.6.zip.
